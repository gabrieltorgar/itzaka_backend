# Contribuir a CUOTREKA (backend)

Este repositorio sigue el flujo de entrega del equipo: `main` y `develop` protegidas, pull requests que solo se fusionan con todas las pruebas en verde y la cobertura mínima, y un commit por historia de usuario o item con sus pruebas, su CHANGELOG y su README.

Las reglas están en un solo lugar:

- **[Reglas de contribución](.claude/rules/contribucion.md)** — ramas, commits, pull requests y cómo proponer un cambio.
- **[Guía de desarrollo](.claude/CLAUDE.md)** — cómo trabaja en el repositorio cualquier persona o agente.
- **[README](README.md)** — qué es, cómo se pone en marcha y cómo se verifica.

¿Quieres proponer un cambio o reportar un problema? Abre un issue (o avisa al responsable del proyecto): entra como item de una iteración. No se aceptan pull requests desde copias del repositorio ni desde ramas fuera del flujo.
